# 📡 NewsArchitect Pro — Automatic News Collector

> "Clean intelligence. Decoded globally."

Terminal news engine that scrapes BBC live, extracts full articles, translates into 15 languages, and narrates with synchronized real-time word highlighting.

## Streams
India · World · Technology · Science · Sports · Business

## Features
- Live Headline Scraper — 15 headlines per stream from BBC
- Full Article Extractor — every paragraph rendered panel by panel
- Voice Sync Engine — per-word highlight synced to audio playback
- 15 Languages — English, Hindi, French, Spanish, German, Japanese, Russian, Arabic, Portuguese, Italian, Korean, Turkish, Bengali, Gujarati, Tamil
- Dual Mode — Visual reader or Voice narration

## Installation
pip install requests beautifulsoup4 gtts pygame deep-translator rich
python Automatic_News_Collecter_Updated.py

## Requirements
Python 3.8+ · Internet connection · Audio output device
