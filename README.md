# 📡 NewsArchitect Pro — Automatic News Collector

> *"Clean intelligence. Decoded globally."*

A terminal news engine that scrapes BBC live, extracts full articles, translates into 15 languages, and narrates with synchronized real-time word highlighting. No browser, no subscriptions, no noise.

| `5` | Sports | BBC Sport |
| `6` | Business | BBC Business |

---

## ⚡ Core Features

| Feature | Description |
|---------|-------------|
| Live Headline Scraper | Pulls 15 headlines per stream from BBC in real time |
| Full Article Extractor | Deep-fetches and renders every paragraph panel by panel |
| Voice Sync Engine | Narrates articles with per-word highlight synced to audio |
| 15-Language Translation | AI-powered translation before voice narration |
| Visual Reader Mode | Structured paragraph-by-paragraph terminal reading |
| Voice Narration Mode | Immersive audio playback with live word highlighting |
